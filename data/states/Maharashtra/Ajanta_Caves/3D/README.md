# 3D Tradition Asset Dropzone

## Target Asset:
`tradition.glb` (or `tradition.gltf`)

## Expected Content:
Interactive 3D cultural model or animation for **Maharashtra (Lavani)**.
- Formats supported: `.glb`, `.gltf`
- Expected naming: `tradition.glb`
- Features supported: PBR materials, skeletal animations, embedded textures, Draco compression.

If `tradition.glb` is placed in this directory, YUGMA's 3D Tradition Viewer will automatically load and render your custom 3D model. If not yet added, YUGMA gracefully provides a high-fidelity procedural 3D cultural interactive experience.
